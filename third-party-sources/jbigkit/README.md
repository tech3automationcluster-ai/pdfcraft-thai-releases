# JBIG-KIT source (GPL-2.0-or-later)

The Thai OCR bundle (`ocr/tesseract/libjbig-0.dll`, loaded by libtiff) is JBIG-KIT 2.1,
built by the MSYS2 project (GCC 13.2.0 Rev2) and shipped in the UB-Mannheim Tesseract 5.4.0 build.
